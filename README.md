# 🎂 Age Calculator

A simple, clean web app that calculates your exact age in **years, months, and days** based on your date of birth — built with vanilla HTML, CSS, and JavaScript.

🔗 **Live Demo:** [nafismahamudshahin.github.io/Age-Calculator](https://nafismahamudshahin.github.io/Age-Calculator/)

---

## 📌 Overview

Age Calculator is a lightweight, no-framework web application that lets users input their date of birth and instantly see their precise age. The project focuses on clean UI, accurate date handling, and simple, readable JavaScript logic — great for practicing DOM manipulation and date/time calculations.

## ✨ Features

- 📅 Select your date of birth using a date picker
- ⚡ Instantly calculates age in **years, months, and days**
- 🎯 Simple, distraction-free, single-page interface
- 📱 Responsive design — works on desktop and mobile
- 🧠 Pure JavaScript logic (no external libraries/frameworks)

## 🛠️ Tech Stack

| Technology | Purpose |
|------------|---------|
| **HTML5**  | Structure & markup |
| **CSS3**   | Styling & layout |
| **JavaScript (Vanilla)** | Age calculation logic & interactivity |

## 🚀 Getting Started

### Run Locally

1. **Clone the repository**
   ```bash
   git clone https://github.com/nafismahamudshahin/Age-Calculator.git
   ```
2. **Navigate to the project folder**
   ```bash
   cd Age-Calculator
   ```
3. **Open `index.html`** in your browser — that's it, no build steps or dependencies required!

### Usage

1. Open the app (locally or via the [live link](https://nafismahamudshahin.github.io/Age-Calculator/)).
2. Enter or select your date of birth.
3. Click the calculate button.
4. View your exact age in years, months, and days.
